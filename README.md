# Matrix Symbol UI

一个以实验平面设计为灵感的单页互动视觉网站。设计语言来自参考作品中的钴蓝色背景、黑白几何结构、透视网格、霓虹彩环、复古衬线字体和颗粒质感。

## 预览网站

无需安装依赖，也不需要启动本地服务器。

1. 双击 `打开网站.cmd`。
2. 或直接使用浏览器打开 `index.html`。

打开后的地址通常以 `file:///E:/原图/matrix-symbol-ui/index.html` 开头。

## 主要功能

- 全屏视觉作品舞台
- 四组视觉状态切换
- 自动轮播与暂停控制
- 上一张、下一张按钮
- 键盘左右方向键切换
- 鼠标移动视差效果
- 作品档案列表
- 桌面端与移动端响应式布局
- 尊重系统“减少动态效果”设置

## 文件结构

```text
matrix-symbol-ui/
```

## 交互操作

| 操作 | 效果 |
| --- | --- |
| 点击左右箭头 | 切换上一张或下一张作品 |
| 按键盘 `←` / `→` | 快速切换作品 |
| 点击右上角暂停按钮 | 暂停或恢复自动轮播 |
| 移动鼠标 | 主视觉产生轻微空间视差 |
| 点击下方作品图版 | 切换作品并返回视觉舞台 |

## 修改内容

作品标题、介绍和图片配置集中在 `app.js` 顶部的 `works` 数组中。新增作品时，还需要在 `index.html` 的 `.plate-list` 中增加对应图版。

主色、纸张色和强调色位于 `styles.css` 顶部的 `:root`：

```css
:root {
  --blue: #1510c9;
  --paper: #f4f2e9;
  --ink: #050505;
  --acid: #eaff19;
}
```

## 技术说明
